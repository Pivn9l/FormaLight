# Forma & Light

Сайт для продвижения продаж дизайнерских зеркал с подсветкой компании **Forma & Light**.

- **Next.js 15** (App Router) + TypeScript
- Шрифт **Playfair Display** (заголовки и текст) + Inter для мелких подписей
- Иконки **Google Material Symbols**
- Админ-панель для управления карточками товаров и ссылками

## Запуск

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000
Админ-панель: http://localhost:3000/admin

## Пароль администратора

Создайте файл `.env.local` (пример — `.env.example`):

```
ADMIN_PASSWORD=ваш-пароль
```

Если переменная не задана, используется пароль по умолчанию `formalight` — обязательно смените его перед публикацией.

## Что умеет админ-панель

- **Товары** — добавление, редактирование, удаление, скрытие с сайта, изменение порядка.
  Поля: название, категория, размер, цена «от», метка (Хит, Новинка), описание.
- **Ссылки и контакты** — Авито, Telegram, Яндекс Маркет, Instagram, TikTok, телефон.
  Заполненные ссылки автоматически появляются в блоке «Контакты», телефон — в шапке,
  а кнопки заказа на карточках ведут в Telegram.

## Данные

Товары и ссылки хранятся в `data/store.json` (создаётся автоматически при первом запуске
с демонстрационными товарами). Для хостинга нужен сервер с Node.js и записываемой файловой
системой (VPS, Timeweb, Selectel и т. п.). На Vercel файловая система только для чтения —
там понадобится подключить базу данных.

## Структура

```
app/
  page.tsx              главная страница
  admin/page.tsx        админ-панель
  api/                  API: auth, products, links
components/             блоки сайта (Header, Hero, Catalog, ProductCard…)
lib/                    типы, хранилище, авторизация, валидация
```
